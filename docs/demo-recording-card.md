# PaperMind 三分钟录屏提示卡

## 录制前

- 浏览器缩放设为 100%，关闭无关标签页和通知
- 提前登录 PaperMind，并在镜头外完成 Zotero 插件连接设置
- 不展示专属链接或设备 ID
- 在 Zotero 里选好一篇带 PDF、标题不含隐私信息的论文
- 先完整走一遍流程，确认 PDF、AI 对话和卡片功能都已加载

## 只记住这一条主线

`Zotero 送入论文 → 在原文上精读 → 把理解沉淀为卡片 → 带入汇报`

## 画面与口播

### 0:00–0:15 开场

画面：Zotero 已选中论文。

口播：

> PaperMind 想解决的不是“再总结一篇论文”，而是把原文阅读、理解和最后的汇报连成一条线。

### 0:15–0:40 从 Zotero 送入

画面：右键论文，选择「用 PaperMind 精读」，等待浏览器打开阅读页。

口播：

> 我可以直接从 Zotero 把文献和 PDF 送进来，不需要重新上传或整理元数据。

### 0:40–1:25 在原文上精读

画面：划选一段真正需要理解的原文，点击「精读这段」，展示拆解结果。

口播：

> 它不是脱离原文给一个泛泛摘要。我划到哪里，它就围绕这段文字解释研究问题、方法和结论边界。

### 1:25–2:05 沉淀成卡片

画面：把刚才的理解保存为卡片，选择「方法」「发现」「批判」或「迁移」之一。

口播：

> 读懂以后不是让答案消失在聊天里，而是把这次理解沉成可回到原文的卡片。

### 2:05–2:35 进入汇报板

画面：把卡片送到汇报板，快速展示已有结构。

口播：

> 卡片可以继续进入汇报板，所以阅读过程中留下的判断，会自然变成后面组会或写作能用的材料。

### 2:35–2:55 收尾

画面：停在汇报板或书架，不再继续点击。

口播：

> PaperMind 的核心不是替我读，而是让我读过的东西能够留下来、连起来，最后真正用起来。

## 录坏时怎么处理

- 说错一句不用立刻停，停两秒后从这句话重新说，后期剪掉即可
- 页面加载超过三秒就暂停口播，等稳定后再继续
- 不临时展示新功能；三分钟只走这一条主线
- 第一次录制只求完整，第二次再调整语速和停顿
